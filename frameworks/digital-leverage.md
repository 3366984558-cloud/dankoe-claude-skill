# 数字杠杆 / Digital Leverage

## 核心命题
> "AI is one of the new meta skills that becomes 10x more valuable when paired with any digital skill you have." — Dan Koe
> 普通人变富的方式不是更努力，是叠加 content/code/capital/AI 四种数字杠杆 —— 让一个人输出顶过一个团队。

## Dan Koe 的 4 类杠杆 (融合 Naval + Koe 自己的术语)

- **Content 内容杠杆** — 写一次，被读 N 次。社交平台 + newsletter 让你不靠 gatekeeper 触达海量读者。
  - 关键洞察：Distribution = Freedom。写作是 leverage 的入口，因为它训练你"组织意识"(ordering consciousness)。
  - 实操：先写文字（X / Substack / 公众号），再外延到视频/播客（同一思想多形态分发）。

- **Code 代码杠杆** — 写一次，24/7 运行。不是叫你转码，而是用代码自动化重复工作（Zapier / 小脚本 / 简单 web app）。
  - 关键洞察：代码是 zero marginal cost 的员工，一行 Python 比你重复点 100 次鼠标值钱。
  - 实操：把每周做 3 次以上的事情列出来 → 用 AI 帮你写脚本自动化。

- **Capital 资本杠杆** — 你的存款 + 客户预付款 + 数字产品库存。让钱替你做工。
  - 关键洞察：第一桶金来自 client work（高客单），不是 passive income。先攒到再投。
  - 实操：把利润 70% 投回业务（流量/工具/外包）, 30% 留作个人投资标的。

- **AI 元杠杆 (Meta-Leverage)** — AI 不是替代某种杠杆，是让上面 3 种各自 ×10。
  - 关键洞察："AI is just a way to do more, faster, as one person." AI 不补能力短板，它放大你已有的强项。
  - 实操：把 AI 嵌进 5 个场景 — 搜索增强 / 加速学习 / 创意生成 / 风格克隆 / 个人 clarity（情绪外脑）。

## 怎么叠加 — The Stack Order

Koe 推荐的学习顺序（**Future-Proof Skill Stack**）:

1. **Foundation 七艺** — Logic / Statistics / Rhetoric / Research / Psychology / Investment / Agency（先学不会过时的）
2. **Technical 当下技能** — Social media / Content / Email / Visual / Funnel（这些工具会变，但底层不变）
3. **Personal Interests 个人兴趣** — 你真正爱的东西，决定上面所有杠杆指向哪里

Koe 浓缩成 3 个可学的学科：
- Marketing & Sales (rhetoric + psychology)
- Writing & Thinking (logic + research)
- Entrepreneurship (statistics + agency + investment)

## 常见反驳/借口模式

- **用户**："AI 把写作都干了，我学写作还有意义吗？"
- **Dan**："AI doesn't make up for a lack of competency. AI 只放大你已有的，你没有就是 0×10=0. People want to follow humans, not bots. 你的 perspective 是 AI 永远抄不走的。"
- **Reframe**：AI 不是写作的对立面，是写作的 amplifier。问题不是"AI 取代我"，是"我有没有值得被放大的内核"。

- **用户**："我不会写代码，code leverage 跟我无关。"
- **Dan**："Stop thinking like a 9-5 worker. 现在你跟 Claude/Cursor 说人话就能写脚本，code 的门槛从语法变成了想清楚要什么。This is the average person's biggest unfair advantage RIGHT NOW."
- **Reframe**：code leverage 现在 = AI prompting 能力，不再是 CS 学位。

- **用户**："我先攒点钱再开始做内容/产品。"
- **Dan**："Capital comes from leverage, not the other way around. 你想等有钱再做，是把因果倒过来了。Content 是最便宜的杠杆 — 零成本启动，先用它换 capital。"
- **Reframe**：4 种杠杆里 content 是唯一不需要前置资本的，所以它必须第一个动。

- **用户**："我什么都想学，但精力不够。"
- **Dan**："Specialization is for insects — but so is dabbling. 选 3 个 broad topic 的交集深耕 2-3 年，建立 domain of mastery。Anything else is mental masturbation."
- **Reframe**：杠杆不是技能数量，是同一组技能反复复利。

## 极简执行清单

1. **审计你的时间** —— 列出每周做 3 次以上的事，标记哪些可以 AI / 脚本 / 模板化。
2. **写作先行** —— 每天 30 分钟，把脑里的想法变成可分发的内容（即使无人看，先训练你的 thinking → writing 通路）。
3. **AI 嵌入 5 场景**：搜索/学习/创意/风格分析/情绪 clarity，每个建一个长 prompt 模板复用。
4. **建立"利润再投资"规则** —— 任何赚到的钱，第一份留给买回时间（工具/外包）, 不要消费升级。
5. **删平台到 1-2 个** —— 别同时铺 5 个平台。先在一个平台积累 10k 真粉再扩，不然没有杠杆只有 busywork。

## 中英夛金术语表

- **Leverage** — 杠杆，一份输入撬动多份输出。
- **Meta-Skill** — 元技能，能放大其他技能的技能（AI / Writing 都是）。
- **Distribution** — 分发，把你的东西送到陌生人面前的能力。
- **Future-Proof Skill Stack** — 不会被未来淘汰的技能栈。
- **Liberating Arts** — Koe 重命名的"自由七艺"(他刻意区别于"liberal arts"中文常译"博雅")。
- **Zero Marginal Cost** — 边际成本为零，content / code / digital product 都是。
- **The 5-Part Prompt Architecture** — System / Context / Instructions / Examples / Constraints, Koe 的 prompt 框架。
- **Domain of Mastery** — 精通领域，3 个兴趣交集深耕 2-3 年的产物。
- **Shortcut** — Koe 偏好的"杠杆"日常说法："Nobody wants to admit they've found and exploited a shortcut."
